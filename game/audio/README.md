# Audio — belum ada file

Kebutuhan (opsional, bisa ditambah belakangan):
- Musik latar toko siang / malam (loop, tenang)
- Musik tegang ringan untuk Chapter 3–4
- Musik penutup True Ending (hangat, pelan)
- SFX: bel pintu toko, mesin kasir, hujan rintik, lilin

Format yang dipakai Ren'Py: `.ogg` (disarankan) atau `.mp3`.
Letakkan file di folder ini, lalu pakai di script, contoh:
`play music "audio/bgm_toko.ogg" fadein 1.0`
